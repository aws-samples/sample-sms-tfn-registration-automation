Toll-Free Programmatic Registration Wizard

AWS End User Messaging SMS
⚠️ Prerequisites
  • AWS CLI v2 installed and configured with credentials
  • AWS Identity and Access Management (IAM) permissions for sms-voice:CreateRegistration, sms-voice:PutRegistrationFieldValue, sms-voice:SubmitRegistrationVersion, sms-voice:RequestPhoneNumber, and sms-voice:TagResource. Scope these permissions to the minimum required resources in your IAM policy.
  • AWS End User Messaging SMS enabled in your target region
💰 Cost Warning

Running the generated CLI commands creates billable AWS resources: toll-free number registration fee and monthly phone number lease. See AWS End User Messaging Pricing for current rates. To remove resources after testing, see the Cleanup section at the bottom of this page.

🔒 Security & Shared Responsibility

This wizard runs entirely in your browser. No data is transmitted to any server — it generates AWS CLI commands that you copy and run locally. Under the AWS Shared Responsibility Model, you are responsible for:

  • Securing your AWS credentials and IAM permissions
  • Protecting sensitive data entered in this form (tax IDs, contact information)
  • Configuring encryption, access controls, and monitoring on deployed resources
  • Ensuring Amazon Simple Storage Service (Amazon S3) buckets used for attachments have Block Public Access enabled, server-side encryption, TLS enforcement, access logging, and versioning
  • Reviewing the Security Hardening Guide before production use

Data sensitivity: This form collects business-sensitive information including company identification numbers (EIN/VAT), contact details, and messaging use case data. This data is used only to generate CLI commands and is not stored or transmitted by this wizard.

🧹 Cleanup — Removing Resources After Testing

To avoid ongoing charges, delete the resources created by this wizard:

  1. Delete the phone number: aws pinpoint-sms-voice-v2 release-phone-number --phone-number-id <PHONE_NUMBER_ID>
  2. Delete the toll-free registration: aws pinpoint-sms-voice-v2 delete-registration --registration-id <REGISTRATION_ID>

Note: Registration fees are non-refundable. Monthly phone number lease charges stop after the number is released.
